# MainSequence-WalkThroughLogistics

Walk through splitters balancers and mergers.

## Status

MSCore migration in progress. No migrated release is published yet. The first integration candidates are Framework and Recipe Clipboard; native game testing is pending.

## Requirements

MSCore 0.8.13 and MainSequenceFramework 0.3.0. Main Sequence, single-player only.

## Installation

Once a tested release is published, add `pobkac-svg/MainSequence-WalkThroughLogistics` in MSCore Manager. The release will include the zip and manifest required by the manager.

Existing native saves and blueprint/underground companion files must be kept when updating. Close the game before manual installation. Do not enable an old standalone copy alongside this addon.
